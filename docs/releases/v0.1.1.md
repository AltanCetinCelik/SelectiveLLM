# SelectiveLLM v0.1.1

Released 2026-09-05.

## What shipped

- A completed real Transformers/PEFT experiment using pinned Qwen2.5-1.5B-Instruct and public code, math, and science LoRI adapters.
- Exact asset revisions, compatibility preflight, input snapshots, content fingerprints, environment data, raw responses, routing decisions, lifecycle telemetry, deterministic evaluations, summary statistics, plots, and failure analysis.
- Real Apple M4/MPS measurements for source-adapter residency, weighted multi-adapter composition, loading, eviction, cache behavior, first-token latency, throughput, live tensor allocation, Metal driver allocation, and host RSS.
- Cache-size 0/1/3 runs under fixed high- and low-locality orders, plus base, random, keyword, oracle, semantic, and all-resident controls.
- A dedicated RLC matrix comparing base, code, science, code-plus-science, semantic, and oracle capacity.

## Evidence

The real run contains 396 primary observations and 18 RLC observations. Semantic routing reached 0.830 warm multi-label F1 versus 0.611 keyword and 0.278 random. Dynamic semantic routing averaged 3125.732 MB MPS live tensor allocation versus 3412.159 MB all-resident, 286.427 MB lower.

That systems result did not become a model-quality result. Semantic, oracle, random, and all-resident all clustered near 0.370 fixed-rubric quality. Random tied oracle, and weighted RLC composition scored below base and code-only. The run therefore demonstrates real adapter-capacity retrieval and residency control, not reliable quality preservation.

## Important limitations

- The workload has only nine authored cases and three warm repetitions.
- The semantic policy uses the project deterministic feature-hash/keyword hybrid, not a learned encoder.
- Policies ran sequentially, so end-to-end cache latency is not a counterbalanced causal estimate.
- The fixed 96-token limit truncated 45.8% of warm responses.
- MPS current and Metal driver allocation are Apple unified-memory signals, not discrete VRAM.
- Weighted-linear derived adapters are composition artifacts and allocate additional memory.
- Nothing in this release implements parameter-level paging inside a dense transformer.
