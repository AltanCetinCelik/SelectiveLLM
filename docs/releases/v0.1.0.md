# SelectiveLLM v0.1.0 - Semantic Expert Routing Prototype

SelectiveLLM v0.1.0 establishes a reproducible framework for testing retrieval over model capacity under explicit memory budgets.

## Highlights

- Multi-label semantic, embedding, keyword, static, random, oracle, top-k, threshold, and hybrid routing.
- Versioned YAML capacity registry and dependency-aware budget planner.
- Memory-aware LRU expert cache with structured lifecycle events.
- Separate declared capacity, observed host RAM, and available accelerator telemetry.
- Shared deterministic-control and Transformers/PEFT backend lifecycle.
- Mixed-domain hero benchmark with hostile baselines, ablations, descriptive statistics, confidence intervals, compatibility fingerprints, failure analysis, Markdown reports, CSV/JSON outputs, and five plots.
- CUDA -> MPS -> CPU detection, Rich CLI, typed Python API, tests, CI, and research documentation.

## Evidence status

The bundled result is produced by `deterministic-control`. It validates routing, budget, cache, reporting, and reproducibility behavior. Declared component capacity is simulated, control task quality is synthetic capability coverage, and accelerator memory is unavailable in that run. These results do not demonstrate physical VRAM savings or language-model quality.

The real Transformers/PEFT backend is configuration-ready, but v0.1 does not bundle model weights or claim a real-adapter result without a compatible licensed asset set.

## Upgrade and compatibility notes

This is the first release. Benchmark, registry, router, and metric schemas have independent versions. Compare run fingerprints before combining evidence.

## Install

```bash
pip install -e .
selectivellm demo
selectivellm benchmark --report --repetitions 3
```

For real model experiments:

```bash
pip install -e ".[hf]"
selectivellm run --config configs/transformers_peft.example.yaml --prompt "Explain a MOSFET gate driver"
```
