# Expert-Quality Diagnostic Results

This directory contains the preregistered 108-generation diagnostic for the
pinned Qwen2.5-1.5B-Instruct base and three public LoRA adapters. Technical
repetitions are not treated as independent benchmark samples.

`latest/` is the immutable completed run. Its formal result is
`expert_pool_viable`: the pool has measurable empirical routing opportunity,
but clean domain specialization and a quality gain from the semantic router were
not established. The post-hoc evaluator sensitivity audit remains separate from
the preregistered result.
